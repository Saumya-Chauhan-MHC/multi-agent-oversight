# All replay files in one folder (copies)

The same files as `v1/` and `v2/`, duplicated into one folder. Names are `<task>_<run>_<tool>`:
- `_v1.jsonl`: my tool, replay 1
- `_v2_monitorA.json` and `_v2_monitorB.json`: Monitor A/B, which is scored as one tool

There are 24 rollouts: `rep0`-`rep3` are single-agent runs and `multi_rep0`-`multi_rep3` are multi-agent runs.
